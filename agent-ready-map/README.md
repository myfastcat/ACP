# Agent Ready Map

Find the safe automation boundary in a real workflow.

Agent Ready Map helps you break a process into steps and decide where an AI agent can act autonomously, where AI should stay in copilot mode, and where a human approval gate belongs.

## What it does

1. Paste a workflow, one step per line.
2. Review each step's judgment, data sensitivity, system access, and reversibility.
3. Get one of three recommendations: **Agent-ready**, **Copilot**, or **Human-gated**.
4. Copy the full operating map as Markdown.

## Privacy

The MVP runs entirely in your browser. It has no backend and does not send your workflow anywhere.

## Run it

Open `index.html` in a browser, or serve this directory with any static web server.

## Good workflows to try

- sales lead qualification;
- customer support escalation;
- invoice processing;
- recruiting coordination;
- software release workflows;
- internal research and reporting.

## Important

This is a workflow-design aid, not a security, legal, or compliance certification.
