# Carry AI Context

> Carry your working context across AI tools without starting over.

## Status

**Launch stage:** Public MVP / validation

Carry AI Context is a lightweight product concept for people who work across multiple AI assistants and repeatedly lose context when switching tools, chats, or workflows.

## Problem

AI users repeatedly re-explain:
- what they are working on;
- decisions already made;
- preferences and constraints;
- current task state;
- what the next AI should do.

This creates context-switching cost and makes multi-AI workflows feel fragmented.

## Product

Carry AI Context turns active working context into a compact, portable handoff that can be carried into another AI conversation or tool.

### MVP workflow

1. Capture the important context from the current work session.
2. Compress it into a portable context package.
3. Carry that package to another AI/tool.
4. Resume with goals, decisions, constraints, and next actions intact.

## Initial target users

- Heavy ChatGPT / Claude / Gemini users
- Developers using multiple AI coding tools
- Founders and knowledge workers running long AI-assisted projects
- Agent builders coordinating work across models

## Validation hypothesis

Users who regularly switch between AI tools will value a simple way to transfer working context enough to try the product and tell us where the handoff breaks.

## Public feedback

Please open a GitHub Issue with:

1. Which AI tools you switch between.
2. What context you currently have to repeat manually.
3. Whether a portable handoff would save meaningful time.
4. The smallest version of Carry you would actually use.
