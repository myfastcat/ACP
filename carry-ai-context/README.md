# Carry AI Context

> Carry your working context across AI tools without starting over.

Carry AI Context helps people move between AI assistants without repeatedly re-explaining the same project, decisions, constraints, and next steps.

## What it does

When you switch from one AI tool to another, Carry gives you a compact handoff containing the context needed to continue the work.

Typical handoff content includes:

- what you are working on;
- decisions already made;
- important constraints and preferences;
- current task state;
- what should happen next.

## Who it is for

Carry is designed for people who regularly work across multiple AI tools, including ChatGPT, Claude, Gemini, coding agents, and other AI assistants.

## Try the current version

The current public version is intentionally small. Use this repository to follow the product and participate in early testing as functionality is released.

4. what the smallest useful Carry workflow would look like for you.
