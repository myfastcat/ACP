# One agent incident → one checked CI regression

**Proposed fixed-price integration service: US$149 once. Booking and checkout are not open yet.** ACP itself remains available under its existing MIT license. The first three assisted pilots advertised in the [trial invitation](https://github.com/myfastcat/ACP/issues/3) remain free.

## Who this fits

A developer maintaining a Python tool-using agent, with a concrete repeated or forbidden action and a runnable test command. Supported OpenAI Agents SDK capture or compatible current-run JSON traces are required. If your existing tests or evaluation platform already cover the incident adequately, this service may add little value.

## What the proposed package includes

One sanitized incident, one customer-reviewed invariant, one scenario-scoped ACP configuration and CI integration patch, and an evidence report showing a normal case and the relevant failing case. Include setup instructions and one revision for the agreed scenario. No production credentials or customer data are needed for initial qualification.

Acceptance is specific: the agreed normal scenario passes, the incident regression fails, and missing trace evidence produces an input error. The customer retains the patch and configuration. This is verification of observed test behavior; it is not runtime prevention, a security audit, a guarantee against future incidents, or an unlimited support subscription.

The service pays for integration and verified delivery. AI can generate tests, and customers comfortable maintaining those tests may prefer doing it themselves. We make no claim that the software is impossible to recreate with AI.
